# Excel Sales Analysis & Dashboard

## Project Overview
This project demonstrates how Microsoft Excel can be used to clean, analyze, and visualize sales data.

## Tools & Skills
- Microsoft Excel
- Data Cleaning and Standardization
- PivotTables
- Data Analysis
- Dashboard Design
- Data Visualization

## Key Metrics
- **Total Sales:** 375,715.36
- **Total Orders:** 3,047
- **Total Quantity Sold:** 5,082
- **Completed Orders:** 2,291
- **Refunded Orders:** 756

## Analysis
The dashboard explores sales performance across:
- Countries
- Sales Channels
- Order Status
- Monthly Sales Trends
- Top-Selling Products

## Workflow
1. Reviewed and cleaned the dataset.
2. Standardized inconsistent country names and date formats.
3. Analyzed sales data using PivotTables.
4. Created charts and an interactive dashboard to summarize key findings.
